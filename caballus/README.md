# Caballus — Sanitized Frontend Demonstration

This folder contains a **standalone frontend demonstration** inspired by an e-commerce interface for personal protective equipment.

## Problem addressed

PPE suppliers need a clear digital catalogue that helps professional buyers quickly browse product categories and request a quote. This demonstration focuses on a clear product discovery experience and a responsive presentation of product categories.

## Included

- Responsive React interface
- Static, fictional catalogue data
- Category-based product discovery layout
- No backend, API client, database, authentication, tracking, client contact details, or proprietary media

## Run locally

```bash
npm install
npm run dev
```

> This is a sanitized portfolio sample, not the production client application.
