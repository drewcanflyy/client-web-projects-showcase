# World Protection Morocco — Sanitized Frontend Demonstration

A static React interface demonstrating a PPE and workwear shopping experience.

## Problem addressed

Safety-equipment businesses need to communicate a broad range of products without overwhelming buyers. This frontend sample presents categories, products and a quote-oriented journey in a simple responsive interface.

## Included

- React + Vite static interface
- Fictional product cards and content
- Catalogue and B2B-quote interaction concept
- No server code, API calls, database, authentication, real company identity, customer data, media, or configuration

## Run locally

```bash
npm install
npm run dev
```

> Sanitized portfolio sample only; it is not the production client application.
