# Client Web Projects Showcase

A curated selection of client web applications designed and developed for Moroccan businesses.

> **Source code is intentionally private.** This repository is a public case-study portfolio: it documents project scope and technology choices without exposing implementation, business data, credentials, or internal assets.

## Projects

### Caballus — PPE supplier platform

A web application created for a company specializing in personal protective equipment (PPE).

**Technology**

- React 19 + Vite
- Node.js + Express
- MySQL
- React Router
- Framer Motion
- Multer for file handling
- XLSX for spreadsheet import/export
- Lucide icons

---

### Ratel — Professional clothing & PPE

A web platform for a professional clothing and PPE business.

**Technology**

- React 19 + Vite
- Node.js + Express
- MySQL
- React Router
- Framer Motion
- Multer
- XLSX
- Compression and CORS middleware
- Lucide icons

### World Protection Morocco — PPE & workwear

## Shared approach

Each project was built with a modern JavaScript stack that separates the user-facing React interface from the server layer, with relational databases for data management. The selected tooling supports responsive interfaces, maintainable routing, media handling, and day-to-day operational workflows.

## Confidentiality

All repositories containing source code, client data, deployment configuration, credentials, and proprietary assets remain private. This public repository exists solely to present the work at a high level.
