# VINGTNEUF — Sanitized Frontend Demonstration

A static React storefront concept for a fashion retailer.

## Problem addressed

Fashion stores need a clean, editorial browsing experience that highlights collections, makes product discovery easy, and stays readable on mobile. This sample focuses on hierarchy, visual rhythm and a collection-first storefront layout.

## Included

- React + Vite frontend sample
- Fictional fashion catalogue content
- Responsive editorial storefront layout
- No backend, API client, checkout, account data, payment flow, tracking, proprietary images, or production configuration

## Run locally

```bash
npm install
npm run dev
```

> Sanitized portfolio sample only; it is not the production client application.
