# Ratel — Sanitized Frontend Demonstration

A static React demonstration for a professional workwear and PPE catalogue.

## Problem addressed

Professional buyers need to find workwear and safety equipment quickly, understand product categories, and move easily toward a quote or sales contact. This sample demonstrates a responsive catalogue-first experience.

## Included

- Static React interface with fictional content
- Category navigation and product-card layout
- Responsive motion-ready visual structure
- No API, backend, database, user accounts, customer data, contact details, proprietary photos, or production configuration

## Run locally

```bash
npm install
npm run dev
```

> Sanitized portfolio sample only; it is not the production client application.
